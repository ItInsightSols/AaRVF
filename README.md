# Responsive Version
All pages except `try.html` have been modified to include a script to switch to `responsive.css` when hieght > width of the screen.

The `responsive.css` contains style rules to properly display the contents of the webpages on a mobile screen.

The webpages having `<table>` have been modified to contain the table in side a `<div>` to properly display the table on a mobile screen, this does not affect normal displaying of the page.
